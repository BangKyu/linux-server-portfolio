# Rocky Linux 기초 명령어

> Rocky Linux에서 자주 사용하는 기본 Linux 명령어 정리
> 
> 
> **디렉터리 이동 → 파일 확인 → 복사/이동 → 생성/삭제 → 파일 내용 확인 → 검색** 순서로 이해하면 편하다.
> 

---

# 1. Change Directory — `cd`

디렉터리를 이동하는 명령어

### 기본 형식

```bash
cd [경로]
```

### 경로 지정 방식

#### 절대 경로

최상위 디렉터리(`/`)부터 이동할 경로를 지정한다.

```bash
cd /home/user
```

#### 상대 경로

현재 위치를 기준으로 경로를 지정한다.

| 기호 | 의미 |
| --- | --- |
| `.` | 현재 디렉터리 |
| `..` | 부모 디렉터리 |
| `~` | 현재 사용자의 홈 디렉터리 |
| `/` | 최상위 디렉터리 |

예시:

```bash
cd ..
```

→ 부모 디렉터리로 이동

```bash
cd .
```

→ 현재 디렉터리

```bash
cd ~
```

→ 홈 디렉터리로 이동

# 2. List — `ls`

현재 또는 지정한 디렉터리의 파일과 디렉터리를 확인하는 명령어

### 기본 형식

```bash
ls [옵션] [경로]
```

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-l` | 파일/디렉터리의 상세 정보 출력 |
| `-a` | 숨김 파일을 포함하여 모두 출력 |
| `-h` | 파일 크기를 사람이 읽기 쉬운 단위로 표시 |
| `-S` | 파일 크기 기준으로 정렬 |
| `-r` | 정렬 결과를 역순으로 출력 |
| `-t` | 수정 시간을 기준으로 최신순 정렬 |
| `-R` | 하위 디렉터리까지 재귀적으로 출력 |

### 자주 사용하는 조합

```bash
ls -al
```

→ 숨김 파일을 포함하여 상세 정보 출력

```bash
ls -lh
```

→ 상세 정보 + 사람이 읽기 쉬운 파일 크기

```bash
ls -alh
```

→ 숨김 파일 + 상세 정보 + 읽기 쉬운 크기

```bash
ls -lt
```

→ 수정 시간이 최신인 파일부터 정렬

> 💡 `ls -l`에서 자주 확인하는 정보
> 
> 
> `권한 → 소유자 → 그룹 → 크기 → 수정 시간 → 파일명`
>

# 3. Copy — `cp`

파일 또는 디렉터리를 복사하는 명령어

### 기본 형식

```bash
cp [옵션] [원본] [목적지]
```

예시:

```bash
cp test.txt backup.txt
```

→ `test.txt`를 `backup.txt`로 복사

```bash
cp test.txt /home/user/
```

→ `test.txt`를 `/home/user/`로 복사

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-p` | 원본의 권한, 소유자, 시간 등의 속성을 최대한 유지 |
| `-u` | 원본이 더 최신인 경우에만 복사 |
| `-R` 또는 `-r` | 디렉터리를 하위 내용까지 재귀적으로 복사 |
| `-i` | 덮어쓰기 전에 확인 |
| `-f` | 기존 파일이 있으면 강제로 덮어쓰기 |

### 디렉터리 복사

```bash
cp -R dir1 dir2
```

→ `dir1` 디렉터리를 `dir2`로 복사

---

## 다중 복사

여러 개의 파일을 한 번에 하나의 목적지 디렉터리로 복사할 수 있다.

### 형식

```bash
cp [파일1] [파일2] [파일3] [목적지 디렉터리]
```

예시:

```bash
cp a.txt b.txt c.txt backup/
```

→ `a.txt`, `b.txt`, `c.txt`를 `backup/`으로 복사

> ⚠️ 다중 복사에서는 마지막 인자가 **목적지 디렉터리**여야 한다.
> 
> 
> 여러 파일을 지정하면서 각각의 파일명을 변경하는 용도로는 사용할 수 없다.
>

# 4. 파일명 매칭 와일드카드

파일이나 디렉터리 이름을 패턴으로 지정할 때 사용하는 특수 문자

`ls`, `cp`, `rm` 등 다양한 명령어에서 사용할 수 있다.

## — Asterisk

**0개 이상의 문자**를 의미한다.

| 패턴 | 의미 |
| --- | --- |
| `A*` | `A`로 시작하는 모든 항목 |
| `*.txt` | `.txt`로 끝나는 모든 항목 |
| `test*` | `test`로 시작하는 모든 항목 |
| `*log*` | 이름에 `log`가 포함된 모든 항목 |

예시:

```bash
ls *.txt
```

→ `.txt` 파일을 모두 출력

```bash
rm test*
```

→ `test`로 시작하는 파일들을 삭제

---

## `?` — Question Mark

**문자 1개**를 의미한다.

| 패턴 | 의미 |
| --- | --- |
| `A?B` | `A`와 `B` 사이에 문자 1개 |
| `???.txt` | 문자 3개 + `.txt` |

예시:

```bash
ls ?.txt
```

→ 한 글자 이름을 가진 `.txt` 파일 검색

```bash
ls ???.txt
```

→ 세 글자 이름을 가진 `.txt` 파일 검색

> ⭐ 암기
> 
> - → **문자 여러 개(0개 이상)**
> 
> `?` → **문자 딱 1개**
>

# 5. Move — `mv`

파일이나 디렉터리를 **이동하거나 이름을 변경**할 때 사용하는 명령어

### 기본 형식

```bash
mv [옵션] [원본] [목적지]
```

### 파일 이동

```bash
mv test.txt /home/user/
```

→ `test.txt`를 `/home/user/`로 이동

### 파일 이름 변경

```bash
mv old.txt new.txt
```

→ `old.txt`의 이름을 `new.txt`로 변경

> 💡 `mv`는 파일과 디렉터리를 특별히 구분하여 사용하는 명령어가 아니다.
> 

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-i` | 덮어쓰기 전에 확인 |
| `-f` | 강제로 덮어쓰기 |
| `-n` | 기존 파일이 있으면 덮어쓰지 않음 |
| `-u` | 원본이 더 최신인 경우에만 덮어쓰기 |

> ⚠️ `mv`는 대상 파일이 이미 존재할 경우 덮어쓸 수 있으므로 주의한다.
>

# 6. Make Directory — `mkdir`

새로운 디렉터리를 생성하는 명령어

### 기본 형식

```bash
mkdir [옵션] [경로/디렉터리명]
```

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-p` | 존재하지 않는 부모 디렉터리까지 함께 생성 |

예시:

```bash
mkdir test
```

→ `test` 디렉터리 생성

```bash
mkdir -p a/b/c
```

→ `a`, `a/b`, `a/b/c`를 필요한 경우 모두 생성

# 7. Remove Directory — `rmdir`

빈 디렉터리를 삭제하는 명령어

### 기본 형식

```bash
rmdir [옵션] [경로/디렉터리명]
```

### 특징

- 디렉터리가 비어 있어야 삭제 가능
- 파일이나 하위 디렉터리가 존재하면 삭제되지 않음
- 일반적으로 디렉터리 삭제에는 `rm -r`을 더 많이 사용

예시:

```bash
rmdir test
```

→ 비어 있는 `test` 디렉터리 삭제

> ⭐ `rmdir` = **빈 디렉터리 삭제**
> 

---

# 8. Remove — `rm`

파일이나 디렉터리를 삭제하는 명령어

### 기본 형식

```bash
rm [옵션] [경로/파일명]
```

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-f` | 확인 없이 강제로 삭제 |
| `-r` 또는 `-R` | 디렉터리와 하위 내용을 재귀적으로 삭제 |
| `-i` | 삭제 전에 확인 |

### 파일 삭제

```bash
rm test.txt
```

→ `test.txt` 삭제

### 디렉터리 삭제

```bash
rm -r test
```

→ `test` 디렉터리와 내부 내용 삭제

### 강제 삭제

```bash
rm -rf test
```

→ `test` 디렉터리와 내부 내용을 확인 없이 강제로 삭제

> ⚠️ **주의**
> 
> 
> Linux의 `rm`은 일반적인 GUI 휴지통으로 이동시키는 명령어가 아니다.
> 
> 특히 `rm -rf`는 매우 위험하므로 **경로와 대상 파일을 반드시 확인한 후 사용**한다.
>

# 9. Concatenate — `cat`

파일의 내용을 터미널에 출력하는 명령어

### 기본 형식

```bash
cat [경로/파일명]
```

예시:

```bash
cat test.txt
```

→ `test.txt`의 전체 내용을 출력

### 특징

- 파일 내용을 한 번에 출력
- 작은 텍스트 파일을 빠르게 확인할 때 유용
- 긴 파일은 화면을 빠르게 지나가기 때문에 `less` 등을 사용하는 것이 좋음
- 일반적인 디렉터리 내용 확인 용도로는 `cat`을 사용하지 않음

# 10. Head — `head`

파일의 **앞부분**을 출력하는 명령어

### 기본 형식

```bash
head [옵션] [경로/파일명]
```

기본적으로 **앞에서 10줄**을 출력한다.

예시:

```bash
head test.txt
```

→ `test.txt`의 처음 10줄 출력

### 원하는 줄 수 출력

```bash
head -n 5 test.txt
```

→ 처음 5줄 출력

또는:

```bash
head -5 test.txt
```

→ 처음 5줄 출력

> ⭐ `head` = **앞부분 확인**
> 

---

# 11. Tail — `tail`

파일의 **뒷부분**을 출력하는 명령어

### 기본 형식

```bash
tail [옵션] [경로/파일명]
```

기본적으로 **뒤에서 10줄**을 출력한다.

예시:

```bash
tail test.txt
```

→ `test.txt`의 마지막 10줄 출력

### 원하는 줄 수 출력

```bash
tail -n 5 test.txt
```

→ 마지막 5줄 출력

### 실시간 로그 확인

```bash
tail -f /var/log/messages
```

→ 파일의 마지막 부분을 출력한 후, 새로운 내용이 추가되면 계속 화면에 출력

> ⭐ `tail` = **뒷부분 확인**
> 
> 
> ⭐ `tail -f` = **실시간 로그 확인**
>

# 12. More — `more`

파일 내용을 **한 화면 단위(page)**로 나누어 출력하는 명령어

### 기본 형식

```bash
more [파일명]
```

예시:

```bash
more test.txt
```

### 다른 명령어와 함께 사용

```bash
ls -l | more
```

→ `ls -l`의 결과를 한 화면씩 확인

### 주요 조작키

| 키 | 기능 |
| --- | --- |
| `Enter` | 한 줄 아래로 이동 |
| `Space` | 한 화면 아래로 이동 |
| `b` | 한 화면 위로 이동 |
| `q` | 종료 |

> `more`는 기본적으로 **앞에서 뒤로 내용을 확인**하는 용도로 사용한다.
>

# 13. Less — `less`

파일 내용을 화면 단위로 나누어 확인하는 명령어

> `more`보다 다양한 이동 기능을 제공하여 긴 파일을 확인할 때 편리하다.
> 

### 기본 형식

```bash
less [파일명]
```

예시:

```bash
less test.txt
```

### 명령어 연동

```bash
ls -l | less
```

→ `ls -l`의 결과를 화면 단위로 확인

### 주요 조작키

| 키 | 기능 |
| --- | --- |
| `j` | 한 줄 아래로 이동 |
| `k` | 한 줄 위로 이동 |
| `gg` | 처음으로 이동 |
| `G` | 마지막으로 이동 |
| `Space` | 한 화면 아래로 이동 |
| `b` | 한 화면 위로 이동 |
| `q` | 종료 |

> ⭐ `less`는 파일을 수정하지 않고 **내용을 탐색하고 확인**할 때 유용하다.
>

# 14. Find — `find`

특정 조건을 기준으로 파일이나 디렉터리를 검색하는 명령어

### 기본 형식

```bash
find [경로] [조건]
```

## 이름으로 검색

```bash
find /home -name "test.txt"
```

→ `/home` 이하에서 이름이 `test.txt`인 항목 검색

### 주요 옵션

| 옵션 | 기능 |
| --- | --- |
| `-name` | 이름을 기준으로 검색 |
| `-type f` | 일반 파일만 검색 |
| `-type d` | 디렉터리만 검색 |
| `-newer` | 특정 파일보다 수정 시간이 최신인 항목 검색 |

### 파일만 검색

```bash
find /home -type f
```

→ `/home` 이하의 일반 파일 검색

### 디렉터리만 검색

```bash
find /home -type d
```

→ `/home` 이하의 디렉터리 검색

### 이름 + 타입 조합

```bash
find /home -type f -name "*.txt"
```

→ `/home` 이하에서 `.txt` 파일만 검색

### `newer`

```bash
find /home -newer test.txt
```

→ `test.txt`보다 **수정 시간이 최신인** 항목 검색

> ⚠️ `-newer`는 일반적으로 "생성 시간"보다는 **파일의 수정 시간(mtime)**을 기준으로 이해하는 것이 정확하다.
>
